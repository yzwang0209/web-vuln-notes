# web-vuln-notes

Web 常见漏洞的复现与成因分析笔记。目标不是"通关"，而是**每一篇都能被追问三层还答得出来**。

## 环境说明

当前所有实验在 **PortSwigger Web Security Academy** 的托管靶场完成（浏览器直接访问，无需本地安装）。
本地复现环境（Docker + DVWA/Vulhub）在期中考试后补，届时会在各篇里补一个"本地复现"小节。

> 为什么先写这个：靶场是谁托管的不重要，**报告里能不能讲清"为什么能利用、怎么修"**才重要。

## 每篇的固定四段

1. **原理**：漏洞成立的条件（不是"因为没过滤"，要说到数据流）
2. **复现**：环境、账号、请求、响应、关键截图
3. **PoC**：最小可复现的请求或脚本
4. **修复**：参数化/白名单/上下文编码，以及"为什么这样修就够"

## 写作纪律

- 每条结论后面要跟证据：截图文件名、请求原文、响应特征。
- 不写"我深入理解了"这类句子；写"我把 X 改成了 Y，返回从 A 变成 B"。
- 写不出来的地方标 `[卡住]`，说明卡在哪一步——这比编一句结论有用。
